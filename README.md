# Cross-Lingual Visual Reasoning in Vision-Language Models

Official research repository for:

**Does Visual Reasoning Transfer Across Languages? Diagnosing and Improving Cross-Lingual Grounding in Vision-Language Models**

## Project objective

This project investigates whether vision-language models preserve visual grounding and reasoning when equivalent questions are presented in English, Bangla, Hindi, Urdu, and English–Bangla code-switched forms.

The study evaluates both:

- language invariance under equivalent multilingual questions;
- visual sensitivity under controlled image interventions.

The project also investigates Cross-Lingual Visual Grounding Consistency Training using LoRA or QLoRA.
